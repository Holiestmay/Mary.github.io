Featured QA Projects

Coffee Shop Ordering Page (UI Automation)

Developed a robust automated end-to-end testing suite to validate the desktop user journey of an e-commerce ordering application.

The Challenge: E-commerce ordering pages require flawless front-end logic to prevent broken cart updates, wrong pricing calculations, or failing confirmation pages.
What I Did:
Configured Cypress to simulate a dedicated desktop environment for layout and element stability.
Automated complete user paths from menu selection to the final checkout step.
Wrote dynamic assertions to verify that adding items accurately updated the cart count and correctly calculated pricing totals.
Audited front-end UI states to ensure successful submissions triggered order confirmations.

User Data API Validation

Built a targeted backend API testing suite to validate user account creation and data entry profiles for a media production platform.

The Challenge:** Data entries like names and email addresses are the foundation of any application's user system and must be accurately processed and managed by the backend.
What I Did:
Mapped out full HTTP request paths to test the complete user lifecycle via **GET, POST, PUT, and DELETE** methods.
Audited input data validation to ensure the backend accurately accepted and structured text entries (names) and email formats.
Monitored endpoint behavior to verify the API consistently returned standard HTTP status codes (like `201 Created` or `200 OK`).
